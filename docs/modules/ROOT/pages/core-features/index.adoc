= Core Features

Arconia knows whether your application is running during development, in tests, or in production, and adapts to it with no configuration:

* xref:core-features/bootstrap-mode.adoc[Bootstrap Mode] detects how the application is launched. It's the single switch that tells every Arconia feature, such as Dev Services, where the application is running.
* xref:core-features/profiles.adoc[Profiles] activates the `dev` and `test` profiles in the matching mode, wherever you launch the application from, so you don't have to configure them in each IDE, build tool, and test class.

== Dependencies

Add the Arconia Spring Boot Starter dependency to your project. The other Arconia starters already include it.

[tabs]
======
Gradle::
+
[source,groovy]
----
dependencies {
  implementation 'io.arconia:arconia-spring-boot-starter'
}
----

Maven::
+
[source,xml]
----
<dependency>
    <groupId>io.arconia</groupId>
    <artifactId>arconia-spring-boot-starter</artifactId>
</dependency>
----
======

Manage its version with the Arconia BOM, as described in xref:getting-started.adoc#_dependency_management[Getting Started].
