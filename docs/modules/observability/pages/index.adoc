= Arconia Observability
:page-aliases: observation:index.adoc

Arconia extends the observability capabilities of Spring Boot applications in two complementary areas.

xref:opentelemetry:index.adoc[OpenTelemetry] combines the standardization of https://opentelemetry.io/docs/what-is-opentelemetry/[OpenTelemetry] with the robustness of https://micrometer.io[Micrometer] to deliver a unified solution that covers logs, metrics, and traces. Add a single dependency and get everything you need, with full support for OpenTelemetry APIs, SDKs, and environment variables.

xref:semantic-conventions/index.adoc[Semantic Conventions] let you choose how telemetry data is named and structured, with no code changes required. Add a dependency to switch from the default Micrometer conventions to the xref:semantic-conventions/opentelemetry.adoc[OpenTelemetry] or xref:semantic-conventions/openinference.adoc[OpenInference] ones, and set a configuration property to adopt the xref:semantic-conventions/openlit.adoc[OpenLIT], xref:semantic-conventions/openllmetry.adoc[OpenLLMetry], xref:semantic-conventions/langsmith.adoc[LangSmith], or xref:semantic-conventions/langfuse.adoc[Langfuse] flavors of the OpenTelemetry conventions for generative AI.
