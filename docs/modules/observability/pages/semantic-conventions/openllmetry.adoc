Spring AI provides built-in instrumentation for models, tools, and agentic workflows based on the Micrometer APIs. Arconia lets you configure your Spring AI applications to export telemetry data adopting the https://traceloop.com/docs/openllmetry[OpenLLMetry Semantic Conventions] instead of the default Micrometer conventions, enabling rich trace visualization in platforms like https://www.traceloop.com[Traceloop].

[WARNING]
====
The https://traceloop.com/docs/openllmetry[OpenLLMetry Semantic Conventions] are still experimental, and they might change in the future.
====

Set the convention flavor to `openllmetry`:

[tabs]
======
YAML::
+
[source,yaml]
----
arconia:
  observations:
    conventions:
      opentelemetry:
        ai:
          flavor: openllmetry
----

Properties::
+
[source,properties]
----
arconia.observations.conventions.opentelemetry.ai.flavor=openllmetry
----

=== Traceloop

Configure the OTLP exporter to send traces to https://www.traceloop.com[Traceloop], making sure you defined your Traceloop API Key in a `TRACELOOP_API_KEY` environment variable:

[tabs]
======
YAML::
+
[source,yaml]
----
arconia:
  otel:
    exporter:
      otlp:
        endpoint: https://api.traceloop.com
        headers:
          Authorization: Bearer ${TRACELOOP_API_KEY}
----

Properties::
+
[source,properties]
----
arconia.otel.exporter.otlp.endpoint=https://api.traceloop.com
arconia.otel.exporter.otlp.headers[Authorization]=Bearer ${TRACELOOP_API_KEY}
----
======

Alternatively, you can use the standard OpenTelemetry environment variables:

[source,env]
----
OTEL_EXPORTER_OTLP_ENDPOINT=https://api.traceloop.com
OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer <your-traceloop-api-key>"
----

== Features

The `openllmetry` flavor records Spring AI observations for Traceloop:

* Chat model, embedding model, and image model calls, following the OpenTelemetry Semantic Conventions for Generative AI, as the current OpenLLMetry instrumentations do.
* Tool executions, with their arguments and result.
* Chat client calls, recorded as Traceloop workflows with their input and output, and grouped into a Traceloop session by the conversation ID of the chat memory.
* Advisors, recorded as Traceloop tasks.
* Token usage, including the total and the cached input tokens.

Content capturing is enabled by default, matching the behavior of the official OpenLLMetry SDKs. Set the `capture-*` properties below to `false` to turn it off.

include::partial$content-capturing-warning.adoc[]

Model calls, embeddings, tool executions, and chat client calls ending in an error get the `error.type` attribute when the xref:semantic-conventions/opentelemetry.adoc#_errors[error conventions] of the Arconia OpenTelemetry Semantic Conventions module are also on the classpath.
