== Disabling the Dev Service

Set the `arconia.dev.services.{service-name}.enabled` property to `false` to disable the Dev Service. To disable it in one mode only, use the profile Arconia activates for that mode (see xref:ROOT:core-features/profiles.adoc[Profiles]), for example in an `application-test.yml` file to disable it in tests:

[source,yaml,subs="attributes"]
----
arconia:
  dev:
    services:
      {service-name}:
        enabled: false
----

To disable it for a single test class, set the property with `@SpringBootTest(properties = ...)` or `@TestPropertySource`. To disable all the Dev Services at once, set `arconia.dev.services.enabled` to `false`.
