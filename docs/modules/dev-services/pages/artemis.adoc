= Artemis Dev Service
:service-name: artemis

A service providing an https://activemq.apache.org/components/artemis/[ActiveMQ Artemis] event broker for development and testing purposes.

It works with Spring Boot libraries that support JMS and ActiveMQ Artemis, including:

* https://docs.spring.io/spring-framework/reference/integration/jms.html[Spring JMS]
* https://docs.spring.io/spring-boot/reference/messaging/jms.html#messaging.jms.artemis[Spring Boot Artemis]

== Running the Application

include::partial$running-application.adoc[]

By default, when running the application in dev mode, multiple applications running simultaneously use the same Artemis Dev Service: the application connects to a running Artemis Dev Service started by another application if available, or else starts its own that other applications can discover in turn. The applications using the same Dev Service must use the same credentials. To always start a container for the application alone, set the `arconia.dev.services.{service-name}.reuse-strategy` property to `none`. Learn more about xref:index.adoc#_reusing_dev_services[Reusing Dev Services].

== Accessing the Management Console

The application logs will show you the URL where you can access the ActiveMQ Artemis Management Console.

[source,logs]
----
...i.a.d.s.startup  : Dev Service 'artemis' is ready in container <container-id> (apache/activemq-artemis, reuse-strategy: framework)
...i.a.d.s.startup  : Dev Service 'artemis' links: Artemis Management Console: http://localhost:<port>/console
----

By default, you can log in with username `arconia` and password `arconia`.

== Configuring the Dev Service

You can configure the Dev Service via configuration properties.

|===
|Property |Default |Description

| `arconia.dev.services.{service-name}.enabled`
| `true`
| Whether the dev service is enabled.

| `arconia.dev.services.{service-name}.image-name`
| `apache/activemq-artemis`
| Full name of the container image used in the dev service.

| `arconia.dev.services.{service-name}.environment`
| `{}`
| Environment variables to set in the service.

| `arconia.dev.services.{service-name}.network-aliases`
| `[]`
| Network aliases to assign to the dev service container.

| `arconia.dev.services.{service-name}.port`
| `0`
| Fixed port for exposing the Artemis' TCP port to the host (CORE, MQTT, AMQP, HORNETQ, STOMP, OPENWIRE). When it's 0 (default), a random available port is assigned dynamically.

| `arconia.dev.services.{service-name}.resources`
| `[]`
| Resources from the classpath or host filesystem to copy into the container. They can be files or directories that will be copied to the specified destination path inside the container at startup and are immutable (read-only).

| `arconia.dev.services.{service-name}.reuse-strategy`
| `framework`
| Strategy for reusing a running container for the dev service instead of starting a new one. With `framework`, the dev service is discoverable by other applications, and the application connects to an existing dev service if available. With `testcontainers`, the container is kept running across application restarts, relying on the Testcontainers reusable containers feature, which must be enabled in the `~/.testcontainers.properties` file; such containers are not stopped automatically and must be cleaned up manually. Only applicable in dev mode.

| `arconia.dev.services.{service-name}.startup-timeout`
| `30s`
| Maximum waiting time for the service to start.

| `arconia.dev.services.{service-name}.volumes`
| `[]`
| Files or directories to mount from the host filesystem into the container. They are mounted at the specified destination path inside the container at startup and are mutable (read-write). Changes in either the host or the container will be immediately reflected in the other.

| `arconia.dev.services.{service-name}.management-console-port`
| `0`
| Fixed port for exposing the Artemis Management Console to the host. When it's 0 (default), a random available port is assigned dynamically.

| `arconia.dev.services.{service-name}.username`
| `arconia`
| Username for the Artemis administrator user.

| `arconia.dev.services.{service-name}.password`
| `arconia`
| Password for the Artemis administrator user.
|===
