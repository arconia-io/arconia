= MySQL Dev Service
:service-name: mysql

A service providing a https://www.mysql.com[MySQL] database for development and testing purposes.

It works with Spring Boot libraries that support MySQL via JDBC, including:

* https://spring.io/projects/spring-data-jdbc[Spring Data JDBC]
* https://spring.io/projects/spring-data-jpa[Spring Data JPA]

[NOTE]
====
This Dev Service is mutually exclusive with other JDBC dev services. If more than one is active at the same time, the application will fail at startup with a clear error message. Disable all but one by setting `arconia.dev.services.<name>.enabled=false`.
====

== Running the Application

include::partial$running-application.adoc[]

Your `@SpringBootTest` integration tests use the Dev Service with no additional configuration, and so do the test slices built on a JDBC data source: `@JdbcTest`, `@DataJdbcTest`, `@DataJpaTest`, and `@JooqTest`. To use Spring Boot's embedded database in a test slice instead, when one is on the classpath, disable the Dev Service for that test with `arconia.dev.services.{service-name}.enabled=false`.

By default, each application starts its own MySQL Dev Service. To let multiple applications running simultaneously in dev mode use the same one, set the `arconia.dev.services.{service-name}.reuse-strategy` property to `framework`: the application connects to a running MySQL Dev Service started by another application if available, or else starts its own that other applications can discover in turn. The applications using the same Dev Service must use the same username, password, and database name. Learn more about xref:index.adoc#_reusing_dev_services[Reusing Dev Services].

== Configuring the Dev Service

You can configure the Dev Service via configuration properties.

|===
|Property |Default |Description

| `arconia.dev.services.{service-name}.enabled`
| `true`
| Whether the dev service is enabled.

| `arconia.dev.services.{service-name}.image-name`
| `mysql`
| Full name of the container image used in the dev service.

| `arconia.dev.services.{service-name}.environment`
| `{}`
| Environment variables to set in the service.

| `arconia.dev.services.{service-name}.network-aliases`
| `[]`
| Additional hostnames the dev service container is reachable by on the shared network, next to the name of the dev service. Only applicable when the shared network is enabled.

| `arconia.dev.services.{service-name}.port`
| `0`
| Fixed port for exposing the MySQL database port to the host. When it's 0 (default), a random available port is assigned dynamically.

| `arconia.dev.services.{service-name}.resources`
| `[]`
| Resources from the classpath or host filesystem to copy into the container. They can be files or directories that will be copied to the specified destination path inside the container at startup and are immutable (read-only).

| `arconia.dev.services.{service-name}.reuse-strategy`
| `none`
| Strategy for reusing a running container for the dev service across applications or restarts. Only applicable in dev mode. See xref:index.adoc#_reusing_dev_services[Reusing Dev Services].

| `arconia.dev.services.{service-name}.startup-timeout`
| `60s`
| Maximum waiting time for the service to start, counted from the container start.

| `arconia.dev.services.{service-name}.volumes`
| `[]`
| Files or directories to mount from the host filesystem into the container. They are mounted at the specified destination path inside the container at startup and are mutable (read-write). Changes in either the host or the container will be immediately reflected in the other.

| `arconia.dev.services.{service-name}.username`
| `arconia`
| Username to be used for connecting to the database.

| `arconia.dev.services.{service-name}.password`
| `arconia`
| Password to be used for connecting to the database.

| `arconia.dev.services.{service-name}.db-name`
| `arconia`
| Name of the database to be created.

| `arconia.dev.services.{service-name}.init-script-paths`
| `[]`
| List of paths to SQL scripts to be loaded from the classpath and applied to the database for initialization.
|===
